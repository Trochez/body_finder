# Implementation status

Body Finder is an experimental, uncertainty-aware search-and-rescue research application. Negative results never prove absence.

## Implemented foundation

- Flutter Android/iOS/Linux project and CI.
- Android/iOS runtime capability inventory.
- Hardware/API/measurement-readiness distinction.
- Safety gate for scientific claims.
- Metric 2D geometry primitive.
- Convex bounded-area geometry.
- Simulation-only metric scenario and dashboard source.
- Adaptive capability ranking.
- Initial local clock-offset model.
- Pull-request build artifacts for Android, iOS, and Linux.

## Validation required

Before additional real-device research functionality is enabled, record the exact phone models and OS versions available for controlled testing. Unsupported or unverified capabilities remain unavailable rather than being inferred.

## User support requested

Provide the exact model and OS version for each Android phone and iPhone available for testing. Four devices are sufficient to begin geometry validation; six to eight provide a stronger perimeter experiment.
